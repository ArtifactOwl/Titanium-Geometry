# Titanium Geometry - Update Package

Copy these files to your project (maintaining folder structure).

## What's New

### Admin App - Now 6 tabs:

1. **Add Product** - Create new products with optional YouTube video

2. **Manage Products** - Full editing:
   - Mark Sold/Pending/Available
   - Edit Price, Description, Group
   - Add/Edit/Remove YouTube video
   - Open images folder
   - Move to Previous Work
   - Delete

3. **Previous Work** - NEW TAB
   - Add items directly to Previous Work gallery
   - Edit name, description, video
   - Delete items
   - Open image folders

4. **Sales/Pricing** - NEW TAB
   - Apply % or $ discount to category or all products
   - Shows original price with strikethrough, sale price in red
   - Remove individual or all sales
   - View all items currently on sale

5. **Groups** - Manage categories

6. **Videos** - Manage all YouTube videos
   - Why Titanium page videos
   - Quick-add video to any product
   - View all product videos

### Website Changes
- Sale prices show with strikethrough original and red sale price
- SALE badge appears on discounted items
- Previous work items can have YouTube videos
